# 컬러 팔레트 — 19색 토큰

모든 화면 색은 `src/company.config.ts`의 `THEME` 한 곳에서 나옵니다. CSS에는 색을 직접 적지 않고,
런타임에 `--color-*` CSS 변수로 주입합니다(`src/DemoApp.tsx`의 `themeStyle`). 색 하나를 바꾸면
앱 전체가 함께 바뀝니다.

설계 의도: **어두운 차콜·네이비 제품 프레임** 안에 **따뜻한 크림 오피스**를 배치해, 픽셀 공간이
스크린 안의 무대처럼 떠 보이게 합니다.

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `app` | `#0b1722` | 제품 바깥 프레임(가장 어두운 배경) |
| `frame` | `#fffaf0` | 어두운 프레임 위 밝은 글자·테두리 |
| `panel` | `#eef7f3` | 패널 배경 |
| `surface` | `#dff1ec` | 패널 안 한 겹 낮은 면 |
| `line` | `#afc9c1` | 구분선·테두리 |
| `edge` | `#315f70` | 강조 테두리 |
| `floor` | `#fff0cd` | 오피스 바닥의 따뜻한 톤 |
| `cream` | `#fffdf5` | 가장 밝은 면 |
| `ink` | `#102b38` | 본문 글자 |
| `muted` | `#4a6872` | 보조 글자 |
| `skin` | `#e0ab84` | 캐릭터 피부 기본값 |
| `wood` | `#b66f3e` | 가구 목재 |
| `woodDark` | `#694229` | 가구 목재 음영 |
| `screen` | `#164761` | 모니터 화면 |

| `shadow` | `#05131c` | 그림자 |

방마다의 포인트 색은 토큰이 아니라 각 공간 정의(`WORKSPACES[n].accent`)가 가집니다 —
브리핑룸 `#f6b73c`, 독자 분석실 `#58b9e8`, 아이디어룸 `#ef71b4`, 제작 스튜디오 `#aa8cf2`,
교정실 `#4fc484`.
